# Vindora Store - Flutter

نسخة متجر Flutter تم تطبيق هوية Vindora البصرية عليها.

## الهوية البصرية
- الكحلي: `#111A32`
- البنفسجي: `#7040F5`
- الأبيض: `#FFFFFF`
- الخلفية الفاتحة: `#F7F7FB`
- الخط المحدد في الثيم: Cairo
- اتجاه الواجهات: RTL

## الموجود حاليًا
- واجهة رئيسية وبانر.
- بحث وتصنيفات.
- شبكة منتجات تجريبية.
- تفاصيل المنتج.
- المفضلة.
- سلة التسوق وتعديل الكميات.
- إجمالي وتجربة طلب محلية.
- صفحة حساب تجريبية.
- الوضع الفاتح والداكن.

## ملاحظات مهمة
- المنتجات والأسعار والسلة ما زالت بيانات تجريبية محلية.
- لم يتم ربط أي API أو قاعدة بيانات في هذه المرحلة.
- تم الإبقاء على وظائف القالب الحالية دون تحويلها إلى وظائف Backend.
- اسم التطبيق الظاهر على Android أصبح Vindora.
- تم حذف مرجع asset غير موجود (`assets/app_icon.png`) من pubspec حتى لا يتعطل جلب الحزم.

## التشغيل
```bash
flutter pub get
flutter run
```

الخطوة التالية بعد اعتماد الثيم: تصميم عقد API وربط المنتجات والحساب والسلة والطلبات بالخادم.
